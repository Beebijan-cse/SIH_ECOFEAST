# EcoFeast 🍃

**Save Food. Connect Communities. Create Impact.**

EcoFeast is a Smart India Hackathon 2026 prototype exploring how institutional kitchens can connect surplus food with NGOs and food banks.

## The idea

Usable surplus food can go to waste when kitchens and organizations that can distribute it have no easy way to connect. EcoFeast brings the proposed process into one place: list surplus food, record safety checks, find potential recipients, and coordinate pickups.

## Prototype features

- Separate dashboards for kitchens, food processing units, NGOs, and administrators
- Screens for surplus listings and food safety checks
- Sample food matching, pickup, and traceability workflows
- A Gemini-powered AI assistant when an API key is configured
- Supabase integration, with local demo data available

## Built with

React · TypeScript · Vite · Tailwind CSS · Node.js · Express · Google AI Studio (Gemini) · Supabase

The prototype is hosted on Vercel: [Open the EcoFeast demo](https://eco-feast-smart-food-waste-reductio.vercel.app).

## Run locally

You’ll need Node.js and npm. From the project folder, run `npm install`, then `npm run dev`.

Supabase and Gemini features require configuration. See `.env.example` for the environment variables.

## Project status

This is a hackathon prototype for demonstrating the concept and user workflows. It uses sample data when the database is not configured and is not a production food-safety or logistics service.
